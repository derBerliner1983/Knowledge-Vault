# Start hier

Willkommen im Knowledge-Vault — einem Second Brain nach der [[Bauanleitung]].

## Der tägliche Kreislauf

1. Alles Neue landet in `00 Inbox` — Notizen, Links, Ideen.
2. Tagesgeschäft in `01 Daily Notes` (Vorlage: [[Vorlage Daily Note]]).
3. Regelmäßig sortieren lassen: Prompt aus [[Prompt-Vorlagen für Claude Code]] —
   Claude schlägt vor, du gibst frei. **Obsidian wird nur von diesem System
   sortiert, nicht von Hand.**
4. Wichtige Quellen ins Wiki einarbeiten lassen (`09 Wiki`, Regeln: [[_SCHEMA]]).

## Die Werkzeuge

- **Katalog:** [[../INDEX|INDEX.md]] — eine Zeile pro Bereich.
- **Suche:** `qmd query "..."` — Bedeutungssuche, komplett lokal.
- **Graph-Ansicht:** im Vault-Ordner `npm install` (einmalig), dann `npm start`
  und im Browser `http://localhost:7777` öffnen.
- **Neu indexieren:** `npm run index` — schreibt `_system/graph.json` und den
  Katalog-Abschnitt der INDEX.md neu.
